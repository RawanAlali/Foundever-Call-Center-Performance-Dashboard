An interactive Power BI dashboard designed to monitor, track, and analyze key operational metrics and performance indicators for Foundever Call Center across multiple projects and months.

---

## 📌 Key Metrics Overview (KPIs)
* **Handling Ratio:** 98.68%
* **Service Level (SL):** 91.06%
* **Abandonment Rate:** 1.32%
* **Average Speed of Answer (ASA):** 9.22 seconds

---

## 💡 Key Features & Visual Insights
* **Monthly ASA Trends:** Bar chart visual tracking Average Speed of Answer across months (*February, March, April*).
* **Project Efficiency Breakdown:** Pie chart highlighting performance and operational efficiency across different client projects (*Project A, Project B, Project C*).
* **Interactive Slicers & Filters:** Seamless filtering capability by **Agent Name**, **Project**, and **Month**.
* **Multi-Page Layout & Navigation:** Custom navigation sidebar with dedicated pages (*Landing Page*, *Analysis Page 1*, *Analysis Page 2*, *Why*).

---

## 🛠️ Tools & Technologies Used
* **Power BI Desktop**
* **DAX** (Custom Data Analysis Expressions & Calculated Measures)
* **Data Modeling & Visualization**
